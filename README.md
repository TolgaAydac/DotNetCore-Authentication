# ASP.NET Core Authentication & Authorization 🔐

ASP.NET Core, JWT (JSON Web Token) ve FluentValidation kullanarak güvenli bir kimlik doğrulama sistemi kurmayı amaçladım. Backend tarafındaki güvenlik mantığını ve kullanıcı yetkilendirme süreçlerini anladığım bir proje oldu.

### 🛠️ Teknik Detaylar
* **Backend:** .NET, C#, Entity Framework Core
* **Güvenlik:** JWT tabanlı Authentication ve Role-based Authorization
* **Validasyon:** FluentValidation ile veri doğruluğu kontrolü
* **Veritabanı:** MS SQL Server

### 🚀 Öne Çıkan Özellikler
- Güvenli kullanıcı kayıt ve giriş optimizasyonu.
- JWT ile stateless oturum yönetimi.
- FluentValidation ile temiz ve merkezi validasyon yapısı.
- Veritabanı işlemleri için optimize edilmiş DbContext mimarisi.
